# 🌿 Minha Rotina — App Aconchegante

> 📱 Aplicativo leve e carinhoso para organizar o dia a dia.  
> **Progresso, não perfeição.** 💛✨

---

## 🐱 Sobre o Projeto

Este é um aplicativo web feito com carinho, pensado especialmente para funcionar bem no celular Android — pode ser instalado igual um app comum! 📲

Ajuda a organizar:
- ✅ Rotina diária (manhã, tarde e noite)
- 💊 Lembrete de remédios
- 📅 Calendário de eventos
- 🤕 Registro de dores de cabeça
- 💤 Tela de descanso total

Tudo fica salvo **direitinho no seu celular** — não precisa de internet depois da primeira vez! 🔒💛

---

## ✨ Funcionalidades

| Área | O que faz |
|---|---|
| 📋 Rotina | Tarefas separadas por horário, marcação quando concluída |
| 💊 Remédios | Marca quando tomou, guarda horário e confirma com carinho 💙🤍 |
| 📅 Calendário | Visualiza dias, cadastra eventos e avisa quando o dia está cheio |
| 🤕 Dor de Cabeça | Registra intensidade, observação e mantém histórico |
| 💤 Descanso | Um espaço pra quando o corpo pede silêncio — sem cobrança 💜 |

---

## 📲 Como Usar

### Pelo navegador
Acesse: `seu-usuario.github.io/minha-rotina`

### Instalar no celular (igual app!)
1. Abra o link acima no **Chrome**
2. Toque nos **3 pontinhos** ⋮ → **Adicionar à tela inicial**
3. Confirme ✅ → vai aparecer o ícone na tela! 🎉
